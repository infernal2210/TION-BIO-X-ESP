# UART и протокол Tuya TION Bio X

## Общие сведения

- UART: 9600 бод, 8N1.
- Заголовок кадров: `55 AA`.
- `CMD=0x00` — heartbeat (наблюдение).
- `CMD=0x06` — передача DP-команды от ESP к контроллеру.
- `CMD=0x07` — отчёт контроллера об изменениях DP.
- UART debug: `>>>` — ESP → контроллер; `<<<` — контроллер → ESP.

## Наблюдавшиеся значения

| DP | Назначение | Наблюдение |
|---:|---|---|
| 101 | Питание | 1 соответствует включённому бризеру |
| 102 | Скорость вентилятора | В логах наблюдались 1–4; диапазон модели — 1–7 |
| 104 | Яркость панели | Наблюдались 0 и 2; шкала 0/50/100% требует проверки |
| 107 | Приток/рециркуляция | 1 — рециркуляция, 0 — обычный режим; независимое управление заслонкой не подтверждено |

Примеры DP107:
- ON: `55 AA 03 07 00 05 6B 01 00 01 01 7C`
- OFF: `55 AA 03 07 00 05 6B 01 00 01 00 7B`

Примеры значения DP104:
- `68 04 00 01 00`
- `68 04 00 01 02`

## Формирование исходящих DP-команд

Для записи datapoint используется команда MCU `CMD=0x06`. Полезная нагрузка одного DP имеет формат:

```text
DP_ID | DP_TYPE | LENGTH_HI | LENGTH_LO | VALUE...
```

Используемые типы:
- BOOL: type `0x01`, длина 1 байт, значение `00` или `01`.
- INTEGER: type `0x02`, длина 4 байта, big-endian.
- ENUM: type `0x04`, длина 1 байт.

Исходящий кадр собирается как `55 AA 00 06 LEN_HI LEN_LO PAYLOAD CHECKSUM`; checksum — младший байт суммы всех байтов кадра до checksum. Формат основан на стандартной структуре Tuya MCU и идентификаторе команды DP-deliver. **Полный исходящий кадр для TION Bio X пока не был зафиксирован отдельным UART-захватом, поэтому запись команд должна считаться предварительной до проверки на подключённом бризере.**

## Неизвестное и ограничения

- DP107 пока нельзя считать независимой командой физической заслонки.
- Инверсию DP105 необходимо подтвердить реальным состоянием нагревателя.
- Значения и диапазоны части DP основаны на модели Tuya и требуют проверки на устройстве.
- Не отправляйте DP109 (заводской сброс) и DP135 (калибровка) при обычном тестировании.
