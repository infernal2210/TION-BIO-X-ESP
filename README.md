# TION BIO X ESP

Проект ESPHome для управления бризером TION Bio X через Home Assistant.

## Версии прошивки

### Full

Полная версия прошивки для TION Bio X с анализатором качества воздуха. Содержит поддержку доступных datapoint устройства, включая данные и настройки анализатора CO2 и PM2.5.

Конфигурация: `esphome/tion-biox.yaml`.

В Full сущности анализатора качества воздуха публикуются условно по DP122:
- значения «Отсутствует» и «Ожидание» — сущности анализатора скрыты;
- значения «Ожидание данных» и «Работает» — сущности анализатора доступны;
- если DP122 не получен за 10 секунд после запуска, сущности остаются скрытыми.

Решение принимается один раз при загрузке контроллера. Если состояние анализатора изменилось уже после запуска, для обновления набора сущностей перезагрузите ESP. Логика реализована локальным компонентом `esphome/components/tion_dp122_gate/`.

Дополнительные сущности Full, отсутствующие в Lite, сохранены и скрыты по умолчанию. Сущности, общие для Full и Lite, используют одинаковые названия и категории.

### Lite

Облегчённая версия для бризеров TION Bio X **без анализатора качества воздуха**. Из Lite удалены лишние datapoint (DP), обработчики и сущности, относящиеся к анализатору CO2 и PM2.5, а также функции калибровки этих датчиков.

Lite сохраняет основные функции управления бризером: питание, вентиляцию, подогрев, рециркуляцию, ночной режим, настройки панели и звуковых сигналов, блокировку от детей, контроль температуры, состояния нагревателя и ресурса фильтра.

В Lite также оставлены сервисные функции ESPHome: уровень сигнала Wi-Fi, время работы контроллера, перезагрузка ESP и сброс счётчика фильтра.

Некоторые редко используемые настройки оставлены в конфигурации, но отключены по умолчанию в Home Assistant.

Конфигурация: `esphome/tion-biox-lite.yaml`.

## Настройка секретов

Перед сборкой создайте файл `esphome/secrets.yaml` на основе `esphome/secrets.example.yaml`.
Укажите собственные значения для Wi-Fi, OTA и резервной точки доступа. Файл `secrets.yaml`
не публикуется в репозитории.

Используются общепринятые имена секретов ESPHome: `wifi_ssid`, `wifi_password`,
`ota_password` и `ap_password`. Одинаковые имена применяются в Full и Lite.

## Важно

Full и Lite являются отдельными конфигурациями. Для Lite используется собственное имя устройства `tion-biox-lite`, поэтому её можно собирать и тестировать независимо от Full.
